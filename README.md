ขั้นตอนที่ 1: ติดตั้ง Django และ Dependencies

ติดตั้ง Django Widget Tweaks
ตัวนี้ช่วยในการปรับแต่งฟอร์มใน Django โดยการเพิ่ม Bootstrap classes หรือการปรับแต่งอื่นๆ ใน template
```bash
pip install django-widget-tweaks
```

ติดตั้ง Django CORS Headers
ใช้สำหรับการจัดการ headers ของ Cross-Origin Resource Sharing (CORS) ใน Django แอปของคุณ
```bash
pip install django-cors-headers
```

ติดตั้ง QRCode
ใช้สำหรับสร้าง QR code ใน Django แอป
```bash
pip install qrcode
```

ติดตั้ง Requests
ใช้สำหรับการส่งคำขอ HTTP ไปยัง API หรือบริการต่างๆ
```bash
pip install requests 
```

ติดตั้ง Pillow
ใช้สำหรับการทำงานกับภาพ เช่น การปรับขนาด การประมวลผล และการบันทึกภาพ
```bash
python -m pip install Pillow
```

ขั้นตอนที่ 2: รันเซิร์ฟเวอร์
หลังจากติดตั้ง dependencies เสร็จแล้ว สามารถรัน Django development server ได้ด้วยคำสั่งนี้:
```bash
python manage.py runserver
```
จะสามารถเข้าไปดูแอปของคุณได้ที่ http://127.0.0.1:8000/ ในเบราว์เซอร์
